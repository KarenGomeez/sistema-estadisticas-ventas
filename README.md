# 📊 Sistema de Estadísticas de Ventas

Sistema web para analizar archivos Excel de agenda de ventas. Permite cargar un archivo, mapear las columnas y obtener estadísticas detalladas con gráficos, filtros y exportación.

## ✨ Funcionalidades

- **Dashboard** con KPIs, gráficos, proyecciones y alertas automáticas
- **Agenda** con tabla filtrable y paginada
- **Comercial** — ranking de vendedores por período
- **Clientes** — listado completo con múltiples filtros
- **Zonas** — trabajos por zona con filtro de tipo de trabajo
- **Planes** — distribución de planes (combina Plan Nuevo + Promoción de instalación)
- **Promociones** — ranking de promociones utilizadas
- **Postventa** — seguimiento de contacto post instalación
- **Bajas** — comparación bajas vs ventas con tasa de baja
- **Comparador de períodos** — compará dos rangos de fechas
- **Reportes** — exportación a Excel y PDF
- **Administración** — gestión de usuarios con roles
- **Modo oscuro** y diseño responsive

## 🛠 Stack

- **Backend:** Python + FastAPI
- **Datos:** pandas, openpyxl
- **Frontend:** HTML + CSS + JavaScript vanilla + Chart.js
- **Auth:** sesiones con cookies httpOnly
